## What's new in 2.4.1: the collection closes with its game

- **Ending a game in Task Manager closes the collection too** (GitHub issue #9). The collection came back whenever a game ended, however it ended, so ending the game in Task Manager only brought the collection's window up again, and it looked like the launcher kept reopening. Now the collection comes back only when you leave a game with its launcher's **Back** or the pause menu's **Quit**. Closing the game's window, ending it in Task Manager or a crash close the collection as well.

Tested with the collection and a game in a test install: Back returns to the collection; ending the game's process closes both.

Everything from 2.4 is in this release: your own music files, and the Streets of Rage 3 ship deck in widescreen.
